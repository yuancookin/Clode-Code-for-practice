# 75日線トレード分析ツール (stock-analyzer)

Yahoo Finance から日足を自動取得し、75日移動平均線を軸にしたトレードルール（`ma75-trading` スキル）で株を分析するコマンドラインツールです。

| 機能 | コマンド | アプリのページ |
|---|---|---|
| 買いの判定・評価・逆指値の価格 | `buy` | 買いの判定 |
| 保有銘柄の利益確定・ロスカットのタイミング判定 | `position` | 保有銘柄の判定 |

コマンドのほかに、ブラウザで使える **アプリ（Streamlit）** もあります → [アプリで使う](#アプリで使うstreamlit)

## 使い方

```bash
cd stock-analyzer
pip install -r requirements.txt

# 日本株は銘柄コードに .T を付ける
python stock_analyzer.py buy 7203.T 6758.T 9201.T 9202.T

# 株数の目安（許容リスク額・投資額の上限）と業績も確認
python stock_analyzer.py buy 7203.T --risk 10000 --capital 500000 --fundamentals

# 売買ルール（買い・利益確定・ロスカット）を過去データで検証
python stock_analyzer.py buy 7203.T --backtest --period 5y

# 保有銘柄の利益確定・ロスカットを判定
python stock_analyzer.py position 7203.T --entry-date 2026-10-14 --entry-price 2378 --shares 100
python stock_analyzer.py position --file positions.csv     # 列: 銘柄,買付日,買値,株数

# ネット接続なしで動作確認（疑似データ）
python stock_analyzer.py buy --demo --backtest
python stock_analyzer.py position --demo
```

## アプリで使う（Streamlit）

左のメニューで2つのページを切り替えます。

- **買いの判定:** 銘柄コード・株価サイトのリンク・株価ファイルを入れると、買いの状況をチャート付きで判定します。
- **保有銘柄の判定:** 保有銘柄（銘柄・買付日・買値・株数）を表に入力するか、一覧ファイル（CSV / Excel）を読み込むと、利益確定とロスカットのタイミングを判定します。チャートには、買い・売りの位置、ロスカットの線、ボリンジャーバンド（+1σ・+2σ）、MACD を表示します。株価は Yahoo Finance から取りますが、株価ファイルを渡すこともできます。

買いの判定の入力方法は次のとおりです。

| 入力方法 | 例 |
|---|---|
| 銘柄コード | `7203`（4桁なら自動で `.T` を付ける）、`6758.T`、`AAPL` |
| 株価サイトのリンク | `https://finance.yahoo.co.jp/quote/7203.T`、`https://finance.yahoo.com/quote/AAPL/`、`https://kabutan.jp/stock/?code=9202`、`https://minkabu.jp/stock/6758` |
| 株価ファイル | 日足の CSV / Excel。列は `日付,始値,高値,安値,終値,出来高`（英語の `Date,Open,High,Low,Close,Volume` も可）。Shift_JIS の CSV も読める。最低120営業日分 |

表示される内容は次のとおりです。
- 判定一覧（CSV で保存可）
- 銘柄ごとのチャート：ローソク足、75日線、逆指値、ロスカット目安、下落前の高値と底、トレンド転換線
- チェック項目、逆指値注文の内容、株数の目安、過去検証の結果


1. このブランチを `main` に取り込む（ブランチのまま公開することもできる）
2. https://share.streamlit.io に GitHub アカウントでログインする
3. 「Create app」→「Deploy a public app from GitHub」を選ぶ

   - Repository: `yuancookin/clode-code-for-practice`
   - Branch: `main`（またはブランチ名）
   - Main file path: `stock-analyzer/app.py`
5. 数分で `https://〇〇.streamlit.app` の URL が発行される。`app.py` と同じフォルダの `requirements.txt` が自動でインストールされる

公開範囲はアプリの「Settings → Sharing」で設定します。自分や指定したメールアドレスだけに限定することもできます。

### アプリの注意点

- Streamlit Community Cloud は、多くのアプリで同じサーバーを共有しています。そのため、Yahoo Finance から取得制限を受けて株価を取得できないことがあります。その場合は、株価ファイルのアップロードを使うか、時間をおいて試してください。
- 取得した株価は15分間保存します。大引け後すぐに最新の終値を取りたいときは、サイドバーの「株価を取り直す」を押してください。
- 業績の確認と過去検証は時間がかかるので、サイドバーで必要なときだけオンにしてください。

## 買いの判定（`buy`）

### 1回目の波：75日線の上抜けで買う

1. 2か月（40営業日）以上の下落
2. 安値を3回以上切り下げ（3段下げ完成）
3. 底から3営業日以上、安値を更新していない
4. 株価が75日線の 5% 以内まで接近（まだ上抜けていない）
5. 25日平均出来高が 10万株以上（`--min-volume` で変更可）

すべて満たすと「買い注文を出す」となり、**75日線＋1呼値以上**の逆指値買いを出します。
有効期限は、翌営業日が属する週の金曜日（今週中）です。

### 2回目以降の波：トレンド転換線

75日線が上向きで、株価が75日線に届かずに反転した銘柄が対象です。

1. 直近40日の調整期間で、高値ローソク足と安値ローソク足を探す（実体で判定）
2. 高値の実体から水平線を引き下ろし、間のローソク足の実体に最初にぶつかった価格を**トレンド転換線**とする
3. 実体が転換線を下から上に抜けた日（転換成立）から1週間、**転換ローソク足の高値＋1呼値以上**の逆指値買いを出す

### ロスカットの目安とリスク

- ロスカットは **約定日の75日線−1呼値以下**。表示されるのは今日の75日線から出した目安で、約定日に確定させます。
- 1株あたりのリスク（買値−ロスカット価格）と、`--risk`（許容損失額）・`--capital`（投資額の上限）から株数の目安を出します。
- 損切り幅が 1% 未満と狭い場合は警告を出します。窓を開けて下がると、損失が想定より大きくなるためです。

### データの鮮度（直近の日付の確認）

75日線と注文価格は毎日変わるため、判定は**終値が確定している直近の取引日**のデータで行う必要があります。

- 取引時間中に取得すると、当日の途中経過の足が含まれます。ルール集の「確定足で判定」に合わせて、この足は自動で除きます。
- データの最終日が直近の取引日より古いときは「◯営業日古い」と警告し、判定に「（要再判定）」を付けます。アプリでは注意の色で表示します。
- 古いデータで出した注文には、「最新データで判定し直してから注文する」と表示します。有効期限が過ぎていれば、それも表示します。
- 取引日は、土日・祝日・年末年始（12/31〜1/3）を除いて数えます。祝日は `jpholiday` で判定します。米国株は土日だけを除きます（米国の祝日は考慮しません）。
- 終値の確定は、大引け（東証 15:30、米国 16:00 現地時間）の30分後とみなします。
- 注文の有効期限は「翌取引日が属する週の最後の取引日」です。金曜が祝日なら、その前の取引日になります。

### 上抜けからの経過で評価を下げる

上抜け（約定）から時間がたつほど、また約定価格から上がるほど、買いの効果は下がります。
そのため、次のように評価を下げます。約定日を0日目として数えます。

| 経過日数 | 約定価格からの値上がり | 扱い |
|---|---|---|
| 0〜1営業日（当日・翌日） | +3% まで | 評価はそのまま |
| 2営業日 | +3% 超〜+5% | 評価を1段階下げる（A→B、B→C） |
| 3営業日以上 | +5% 超 | **見送り**（追いかけ買いしない）。評価は C |

- 日数と値上がりのうち、厳しい方の扱いになります。
- データが古い場合は、その営業日数も経過日数に足します。
- しきい値は `buy.py` の `ELAPSED_OK_DAYS`・`ELAPSED_LATE_DAYS`・`GAIN_OK`・`GAIN_LATE` で変えられます。

### 評価

| 判定 | 意味 |
|---|---|
| 買い注文を出す | 逆指値の価格・期限・ロスカットの目安を表示 |
| 上抜け済み | 直近に買いの条件を満たして上抜けた（注文していれば約定） |
| 見送り | 上抜けから3営業日以上たった、または約定価格から5%超上がった |
| トレンド転換待ち | 2回目の波。転換線の価格を表示 |
| ウォッチリスト | 底値から1回目を準備中など |
| 対象外 | 75日線が下向きで株価がその下、底を確認できない |

評価は **A**（必須条件すべて＋加点2つ以上）／**B**（必須条件すべて）／**C**（必須条件に未達あり）です。
加点項目は「75日線の下げ止まり」「直近が陽線（下ヒゲの長い陽線など）」「増収増益（`--fundamentals`）」です。
業績は売買の引き金にはせず、加点にだけ使います。

### 出力例

```
=== 1234.T  (2026-10-02 終値 935円) ===
  判定: 買い注文を出す【1回目の波】  評価: B
  底を確認し75日線に接近。75日線の上抜けで買い
   ✓ 下落期間 97営業日（2026-04-03 の高値から）
   ✓ 安値の切り下げ 3回（3段下げ完成）
   ✓ 底 821円（2026-08-18）から 33営業日、安値更新なし
   ✓ 株価は75日線の 0.2% 下（接近）
   ✓ 出来高 25日平均 595,910株/日
   ・ 75日線の傾き -2.9%/10日（まだ下向き）
   + 直近のローソク足: 大きな陽線（一方向に強い）
  逆指値注文:
   買い      : 937円 以上になったら 937円 で買い（75日線 936.66 ＋1呼値、有効期限 2026-10-09(金) まで）
   ロスカット: 936円 以下で売り（目安＝今日の75日線−1呼値。約定日の75日線で確定させる）
   リスク    : 1株 1円 → 100株で 100円
   株数の目安: 500株（投資上限 500,000円で決定、投資額 468,500円）
   ⚠ 損切り幅が 0.1% と狭い。窓を開けて下がると損失は想定より大きくなる
```

## 保有銘柄の判定（`position`）

買付日から1日ずつ進めて、最初に出た売りのシグナルを判定します。判定は、その日の終値までのデータだけで行います。

### ロスカット

- **約定日の75日線−1呼値「以下」**で逆指値売りです。約定後は動かしません。
- 値幅注文として、逆指値から5呼値下まで約定を許します（`position.py` の `STOP_SLIP_TICKS`）。
- 窓を開けて逆指値より下で寄り付いた場合は、始値で約定したとみなします。
- 1株あたり・保有株数分のリスク額を表示します。

### 利益確定

| ルール | いつ売るか |
|---|---|
| MACD：約定後（5営業日以内）にゴールデンクロスしてトレンドを確認 → 乖離（ヒストグラム）が縮んだ | 翌営業日の寄り付き |
| ボリンジャーバンド（25日）：トレンド発生前に +2σ に到達 | その日（前日の +2σ を指値の目安にする） |
| ボリンジャーバンド（25日）：トレンド発生中に、一度 +1σ の上に出た終値が +1σ を割った | 翌営業日の寄り付き |

- 「トレンド発生中」は、ルール集 3 の上昇トレンド（75日線が上向きで、株価がその上）で判定します。1回目の波（底からの上抜け）は75日線がまだ下向きなので「発生前」、2回目以降の波は「発生中」になりやすいです。
- 約定した時点ですでに MACD がシグナルの上にある場合は、新しいゴールデンクロスが無いため、MACD のルールは使いません。
- MACD とボリンジャーバンド（+1σ）のシグナルは、**含み益のときだけ**使います。含み損のときはロスカットで管理します。

### 判定

| 判定 | 意味 |
|---|---|
| ロスカット | 逆指値に到達した（当日、またはすでに約定しているはず） |
| 利益確定 | 翌営業日の寄り付きで売る、または +2σ で売れた（はず） |
| 保有継続 | 売りのシグナルなし。ロスカットの逆指値は置いたまま |

データの鮮度の確認（取引時間中の足の除外、古いデータの警告）は、買いの判定と同じです。

## 過去検証（`--backtest`）

- 各営業日の終値までのデータだけで判定し、「買い注文を出す」なら翌営業日に逆指値を置きます。約定するまで、価格は毎日見直します。
- 高値が逆指値に届いたら約定とします。寄り付きで超えていた場合は始値で約定します。
- 約定後は、保有銘柄の判定と同じ利益確定・ロスカットのルールで売ります。売った日の終値から、また買いを判定します。
- 取引回数・勝率・平均リターン・損益比・最大ドローダウン・ロスカット率を表示します。手数料とスリッページは含みません。

### 多数の銘柄から買い候補を探す（スクリーニング）

```bash
python screen.py                     # 東証プライムの主要60銘柄
python screen.py 7203.T 6758.T --out screen.md
```

直近の終値で買いの判定をかけ、「買い注文を出す」「トレンド転換待ち」「上抜け済み」の銘柄を、逆指値とロスカットの目安付きで一覧にします。
GitHub Actions でも push 時・手動実行時に動き、結果を Summary に出します。

### 実際の銘柄でまとめて検証する

```bash
python backtest_report.py                         # 東証プライムの主要30銘柄・5年
python backtest_report.py 7203.T 6758.T --period 10y --out report.md --csv trades.csv
```

全体と売った理由ごとに、勝率・平均リターン・損益比・**ロスカット率**・ロスカットまでの日数を集計し、さらに銘柄別の結果も Markdown の表で出します。

GitHub Actions（`.github/workflows/stock-analyzer.yml`）でも、このブランチや main に push したときに実行されます。結果は実行画面の Summary と、成果物（backtest-report）で確認できます。手動で実行する場合は、Actions タブの「Stock analyzer」→「Run workflow」から、銘柄と期間を指定できます。

## 注意点

- 呼値は東証の標準の刻みを使っています。TOPIX500 構成銘柄はもっと細かい刻みがあるため、注文時に確認してください。

# 株価分析ツール (stock-analyzer)

Yahoo Finance から株価を自動取得し、**3つのテクニカル分析**を同時に実行して買いシグナルを判定するコマンドラインツールです。

## 3つの分析手法

| 手法 | 見ているもの | +2（強い買い材料） | -2（強い売り材料） |
|---|---|---|---|
| 移動平均線 (SMA25 / SMA75) | トレンド | 直近5日以内のゴールデンクロス | 直近5日以内のデッドクロス |
| RSI (14日) | 売られすぎ / 買われすぎ | 30未満から反発中 | 70超（買われすぎ） |
| MACD (12, 26, 9) | 勢いの転換 | 直近3日以内にシグナル線を上抜け | 直近3日以内に下抜け |

各手法のスコア（-2〜+2）を合計し、`+4以上: 強い買い` / `+2以上: 買い` / `-1〜+1: 様子見` / `-2以下: 売り` / `-4以下: 強い売り` と判定します。

## 使い方

```bash
cd stock-analyzer
pip install -r requirements.txt

# 日本株は銘柄コードに .T を付ける（トヨタ=7203.T, ソニー=6758.T）。米国株はそのまま
python stock_analyzer.py 7203.T 6758.T 9984.T AAPL

# 過去データで「買いシグナル後20日」の勝率・平均リターンを検証
python stock_analyzer.py 7203.T --backtest --period 2y

# ネット接続なしで動作確認（疑似データ）
python stock_analyzer.py --demo
```

出力例:

```
=== 7203.T  (2026-10-09 終値 2,845.00) ===
  [+2] 移動平均線: 直近5日以内にゴールデンクロス (SMA25 が SMA75 を上抜け)
  [+0] RSI: 中立 (RSI 58.3)
  [+1] MACD: MACD > シグナル、ヒストグラム拡大中
  総合スコア +3 / ±6  →  判定: 買い
```

複数銘柄を指定すると、最後にスコア順の「買い候補ランキング」が表示されます。

## テスト

```bash
pip install pytest
python -m pytest -q
```

## 注意点

- 移動平均・MACD はトレンドに乗る手法、RSI は逆張りの手法です。強い上昇相場では RSI が「買われすぎ」でマイナスを出すため、総合判定が控えめになります。
- `--backtest` は同じ銘柄の過去で判定ルールを試すだけの簡易検証で、手数料などは考慮していません。
- データ取得には非公式ライブラリ `yfinance` を使っています。Yahoo 側の仕様変更で取得できなくなることがあります。

# 株価分析ツール (stock-analyzer)

Yahoo Finance から株価を自動取得し、**3つのテクニカル分析**を同時に実行して買いシグナルを判定するコマンドラインツールです。

## 3つの分析手法（買い分析）

| 手法 | 見ているもの | +2（強い買い材料） | -2（強い売り材料） |
|---|---|---|---|
| ボリンジャーバンド (20日, ±2σ) | 売られすぎ / 過熱 | -2σ にタッチ後、バンド内へ反発 | +2σ 超え |
| 75日移動平均線 | 中期トレンド | 75日線が上向きで株価が上 | 75日線が下向きで株価が下 |
| グランビルの法則 (25日線) | 移動平均線と株価の関係 | 買い①（転換点の上抜け）・買い②（押し目からの回復） | 売り①（転換点の下抜け） |

グランビルの法則は、買い③（移動平均線で反発）と買い④（大きく下に離れた後の自律反発）を +1 とします。
75日線とは役割を分けるため、グランビルには短期の25日線を使います。

MACD は買い判定には使いません。売り分析を追加するときに使う予定で、コード (`analyze_macd`) だけ残しています。

各手法のスコア（-2〜+2）を合計し、`+4以上: 強い買い` / `+2以上: 買い` / `-1〜+1: 様子見` / `-2以下: 売り` / `-4以下: 強い売り` と判定します。

## 使い方

```bash
cd stock-analyzer
pip install -r requirements.txt

# 日本株は銘柄コードに .T を付ける（トヨタ=7203.T, ソニー=6758.T）。米国株はそのまま
python stock_analyzer.py 7203.T 6758.T 9984.T AAPL

# 過去データで「買いシグナル後20日」の勝率・平均リターンを検証
python stock_analyzer.py 7203.T --backtest --period 2y

# ネット接続なしで動作確認（疑似データ）
python stock_analyzer.py --demo
```

出力例:

```
=== 7203.T  (2026-10-09 終値 2,845.00) ===
  [+2] ボリンジャーバンド: -2σ にタッチ後、バンド内へ反発 (-1.6σ)
  [+2] 75日移動平均線: 75日線は上向き (+1.8%/10日)、株価は75日線の上
  [+2] グランビル(25日線): 買い②: 上向きの移動平均線を一時割り込んだ後、再び上抜け
  総合スコア +6 / ±6  →  判定: 強い買い
```

複数銘柄を指定すると、最後にスコア順の「買い候補ランキング」が表示されます。

```bash
pip install pytest

```

## 注意点

- ボリンジャーバンドは逆張り、75日線とグランビルはトレンド重視の手法です。強い上昇相場では、ボリンジャーバンドが +2σ 超えでマイナスを出すため、総合判定が控えめになります。
- 分析には最低90営業日分のデータが必要です（既定の `--period 1y` で足ります）。
- `--backtest` は同じ銘柄の過去で判定ルールを試すだけの簡易検証で、手数料などは考慮していません。
- データ取得には非公式ライブラリ `yfinance` を使っています。Yahoo 側の仕様変更で取得できなくなることがあります。

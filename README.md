# TaskFlow — 高機能タスク管理アプリ

ビルド不要のバニラ JavaScript（ES Modules）で作った、多機能なタスク管理アプリです。
データはブラウザの `localStorage` にのみ保存され、サーバーへは何も送信しません。

## 主な機能

### タスク管理
- **タスク項目**：タイトル・メモ・ステータス（未着手 / 進行中 / 完了）・優先度（高 / 中 / 低 / なし）
- **期限**：日付＋時刻、期限切れ・今日・N日後を色分けしたバッジで表示
- **サブタスク**：チェックリストと進捗バー
- **くり返し**：毎日 / 平日のみ / 毎週（曜日指定可）/ 毎月 / 毎年 / N日ごと
  - 完了すると自動で次回の期限へ送られ、サブタスクのチェックもリセットされます
- **プロジェクト**と**タグ**（複数付与可、色つき）
- **見積りポモドーロ数**、実績ポモドーロ数
- **アーカイブ**と**ゴミ箱**（30日で自動削除、復元可）

### 4つのビュー
| ビュー | 内容 |
| --- | --- |
| リスト | グループ化（プロジェクト / タグ / 優先度 / 期限 / 状態）、ドラッグで並べ替え |
| ボード | 未着手・進行中・完了のカンバン。列間ドラッグでステータス変更 |
| カレンダー | 月表示。日付へドラッグして期限変更、日を選ぶとその日の一覧と追加欄 |
| 統計 | 完了数の推移・完了率・連続達成日数・優先度分布・プロジェクト別進捗 |

### 入力と操作
- **自然文クイック入力**
  `資料をまとめる 明日 15:00 !高 @仕事 #会議 毎週` のように書くと、期限・時刻・優先度・プロジェクト・タグ・くり返しを自動で解釈します（入力中にプレビュー表示）
- **コマンドパレット**（`Ctrl` / `⌘` + `K`）でビュー切り替え・移動・タスク検索
- **横断検索**：タイトル・メモ・サブタスク・プロジェクト名・タグ名（複数語は AND 検索）
- **複数選択と一括操作**（`Ctrl` / `⌘` + クリック、または `X`）：完了・優先度変更・プロジェクト移動・アーカイブ・削除
- **元に戻す / やり直す**（`Ctrl` / `⌘` + `Z`）
- キーボード操作（`J` / `K` で移動、`Enter` で詳細、`Space` で完了、`Delete` で削除）

### その他
- **ポモドーロタイマー**（作業 / 小休憩 / 長休憩、完了数をタスクに記録）
- **期限リマインダー**（ブラウザ通知、未許可時はアプリ内トースト）
- **ライト / ダークテーマ**（OS 追従 + 手動切り替え）とアクセントカラー変更
- **JSON / CSV エクスポート**、**JSON インポート**（追加 / 置き換え）
- 旧バージョンの Todo アプリのデータは初回起動時に自動で移行されます

## 使い方

ES Modules を使っているため、`index.html` をファイルとして直接開くのではなく、
HTTP サーバー経由で開いてください。

```bash
# 任意の静的サーバーで OK
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages へは `main` ブランチへの push で自動デプロイされます。

## 開発

```bash
npm test   # ロジック層のユニットテスト（node:test）
```

テストは DOM に依存しない純粋モジュール（日付計算・スキーマ移行・くり返し・
絞り込み / 並べ替え / 集計・自然文パース）を対象にしています。

## 構成

```
index.html          アプリのシェル
style.css           デザイントークンと全コンポーネントのスタイル
src/
  main.js           エントリポイント（配線と描画の起点）
  store.js          状態管理・localStorage 永続化・Undo/Redo
  model.js          スキーマ定義・正規化・移行・くり返し計算
  query.js          絞り込み・並べ替え・グループ化・統計
  date.js           日付ユーティリティ
  quickparse.js     自然文クイック入力のパーサ
  utils.js          DOM 生成などの共通処理
  views/            list / board / calendar / stats
  ui/               サイドバー・ツールバー・詳細パネル・モーダル・パレットなど
  features/         ポモドーロ・通知・バックアップ
tests/              node:test によるユニットテスト
```

### 表示性能について
- タスク行の DOM をキャッシュしてキー付きで並べ替え、内容は「署名」が変わった行だけ更新
- イベントはリスト単位で委譲（行ごとに listener を張らない）
- 変更通知は `requestAnimationFrame` でまとめ、保存はデバウンス
- 一覧は 300 件ずつの段階表示

1,000 件を超えるタスクでも再描画は数ミリ秒で完了します（状態バー右端に実測値を表示）。

# ClipStudio

ブラウザだけで完結する動画編集アプリです。素材はサーバーにアップロードされず、すべて端末内（メモリ上）で処理されます。ビルド不要の素の HTML / CSS / JavaScript (ES Modules) 製で、GitHub Pages にそのまま配信できます。

## 主な機能

- **タイムライン編集**: 映像 / 音声 / テキストの 3 トラック。ドラッグで並べ替え・移動、両端のハンドルでトリム、再生位置での分割 (`S`)、複製、削除
- **プレビュー**: Canvas 合成によるリアルタイム再生。コマ送り、`J` / `K` / `L` シャトル、ループ、スナップ付きスクラブ
- **トランジション**: クロスフェード / 黒フェード / ワイプ / スライド / ズーム（長さも調整可、クリップは自動で重なります）
- **クリップ調整**: 再生速度 (0.25〜4x)、音量、フェードイン・アウト、表示方法（全体表示 / 画面いっぱい / 引き伸ばし）、拡大・位置・回転・反転
- **色調補正**: 明るさ / コントラスト / 彩度 / 色相 / ぼかし / モノクロ / セピア と、ビビッド・ヴィンテージなどのプリセット
- **テロップ**: フォント・サイズ・色・背景・位置・揃え・影に加え、フェード / スライド / ポップ / タイプライターのアニメーション
- **音声**: BGM やナレーションを自由な位置に配置。クリップ音量とフェード、Web Audio によるミックス
- **書き出し**: MP4 / WebM（ブラウザ対応形式を自動判定）、解像度・fps・ビットレート指定、進捗表示と中止。現在のフレームを PNG 保存も可能
- **プロジェクト管理**: JSON で保存 / 読み込み、`localStorage` への自動保存
- **サーバー連携（任意）**: 付属の FastAPI バックエンドに素材を自動アップロードし、次に開いたときに自動で復元。サーバー上の素材一覧からの読み込みにも対応（バックエンドなしでも今までどおり動きます）
- **AI アシスタント（任意）**: 自然言語での編集指示、タイトル・説明文の生成、自動字幕、ハイライト抽出（Claude API を使用、バックエンド必須）
- **その他**: 取り消し / やり直し、ダークモード、キーボードショートカット、PWA（オフライン対応・ホーム画面に追加）
- 素材が手元になくても、メニューの「サンプル素材を生成」で動作を試せます

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` `→` | 1 コマ移動（`Shift` で 1 秒） |
| `J` `K` `L` | 逆再生 / 停止 / 再生（連打で倍速） |
| `Home` `End` | 先頭 / 末尾へ |
| `S` | 再生位置で分割 |
| `T` | テロップを追加 |
| `Delete` | 選択中のクリップを削除 |
| `Ctrl/Cmd+D` | 複製 |
| `Ctrl/Cmd+Z` | 元に戻す（`Shift` 併用でやり直す） |
| `M` | ミュート |
| `+` `-` `F` | タイムラインの拡大 / 縮小 / 全体表示 |
| `?` | ショートカット一覧 |

## 仕組みと制限

- プレビューと書き出しは `<video>` の再生を `<canvas>` に合成する方式です。書き出しは `MediaRecorder` による録画のため、**動画の長さと同じ時間がかかり**、完了までタブを開いたままにする必要があります。
- 音声は Web Audio (`MediaElementSource` → `GainNode` → `MediaStreamDestination`) でミックスして録画ストリームに合成します。
- 出力形式はブラウザが対応するものだけを表示します（Chrome / Edge は MP4・WebM、Firefox は WebM）。
- ブラウザ単体では素材ファイル自体を保存できないため、保存されるのはプロジェクト（クリップ構成や設定）だけで、再読み込み後はメディア一覧の 🔗 ボタンから再リンクします。下記のバックエンドに接続していれば、素材はサーバーから自動で読み込まれるので再リンクは不要です。

## バックエンド (FastAPI)

素材をサーバーに保存しておくための API です。エディタ本体も同じサーバーから配信されるので、これだけ起動すれば使えます。

```sh
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload     # http://127.0.0.1:8000 でエディタが開く
```

| メソッド | パス | 内容 |
| --- | --- | --- |
| `GET` | `/` | エディタ本体（`index.html`）|
| `POST` | `/upload` | 動画・写真を複数まとめてアップロードし、保存したファイル一覧を JSON で返す |
| `GET` | `/files` | `uploads/` に保存済みのファイル一覧を新しい順で返す |
| `GET` | `/uploads/{name}` | 保存したファイルをそのまま配信 |
| `GET` | `/api` | API の情報（保存先・上限・対応拡張子・AI の有無）|
| `POST` | `/ai/*` | AI 機能（下記）|
| `GET` | `/docs` | 自動生成される API ドキュメント |

```sh
curl -X POST http://127.0.0.1:8000/upload \
  -F "files=@opening.mp4" -F "files=@cover.png"
```

```json
{
  "files": [
    {
      "name": "20260929-065018_6318353f_cover.png",
      "original_name": "cover.png",
      "kind": "image",
      "content_type": "image/png",
      "size": 95316,
      "url": "/uploads/20260929-065018_6318353f_cover.png",
      "uploaded_at": "2026-09-29T06:50:18.842453+00:00"
    }
  ],
  "rejected": []
}
```

- 保存先は `uploads/`（中身は Git 管理外）。保存名は `日時_ランダム_元の名前` で衝突せず、パス区切りを含む名前を送られても `uploads/` の外には書き込みません。
- 対応形式は動画 (`.mp4` `.webm` `.mov` `.m4v` `.avi` `.mkv` `.ogv`) と画像 (`.png` `.jpg` `.jpeg` `.gif` `.webp` `.avif` `.bmp` `.svg`)。対象外・空・サイズ超過のファイルは `rejected` に理由付きで返し、残りは保存します（1件も保存できなければ 400）。
- 配信するフロントエンドのファイルは `index.html` / `style.css` / `sw.js` / `manifest.json` と `js` `icons` `fonts` ディレクトリに限定しています（リポジトリの他のファイルは公開されません）。
- 環境変数: `CLIPSTUDIO_UPLOAD_DIR`（保存先）、`CLIPSTUDIO_MAX_UPLOAD_MB`（1ファイルの上限、既定 2048）、`CLIPSTUDIO_ALLOW_ORIGINS`（CORS 許可オリジン、既定は全許可）

### エディタ側の使い方

ヘッダーの ☁ ボタンから「サーバー連携」を開きます。

- **同じサーバーから配信している場合**（上記の `uvicorn` だけで動かす場合）は設定不要です。起動時に自動で接続します。
- **エディタを別のポートで配信している場合**は、ダイアログの「API の URL」に `http://127.0.0.1:8000` のように入力して「接続を確認」を押します（設定はブラウザに保存されます）。
- 接続できていると、取り込んだ素材は自動でアップロードされ（自動アップロードはオフにもできます）、メディア一覧に ☁ が付きます。
- 次回以降はプロジェクトを開くだけで、サーバー上の素材が自動で読み込まれます（再リンク不要）。サーバーに無い素材だけ 🔗 から手動で再リンクします。
- ダイアログの一覧から、サーバー上の素材を直接プロジェクトへ読み込めます。

## AI アシスタント（任意）

ヘッダーの ✨ AI ボタンから開きます。バックエンドに `ANTHROPIC_API_KEY` を設定すると有効になります。

```sh
export ANTHROPIC_API_KEY=sk-ant-...
uvicorn backend.main:app --reload
```

| タブ | できること | 使う API |
| --- | --- | --- |
| 🎬 編集する | 「最初の3秒をカットして、全体をセピアに」のような指示をタイムラインに反映 | `POST /ai/edit` |
| ✍ タイトル | タイトル3案・説明文・ハッシュタグ・チャプター・テロップ案を生成 | `POST /ai/titles` |
| 💬 字幕 | 素材を文字起こしし、読みやすく整えた字幕をテロップとして配置 | `POST /ai/transcribe` |
| ⭐ ハイライト | 文字起こしから短尺向きの区間を選び、クリップとして追加 | `POST /ai/highlights` |

- モデルは既定で `claude-opus-5-5`（`CLIPSTUDIO_CLAUDE_MODEL` で変更可）。API キーはサーバー側だけに置き、ブラウザには渡しません。
- 編集指示は「操作の列」を構造化出力で受け取り、アプリ側で検証してから適用します。存在しないクリップを指す操作などは適用せず、理由を表示します。**AI の編集はまとめて 1 回の取り消し (Ctrl+Z) で元に戻せます。**
- 字幕は ffmpeg で音声を取り出し、ローカルの faster-whisper で文字起こしします（音声認識自体に API 料金はかかりません）。使う場合は追加インストールが必要です。

  ```sh
  pip install faster-whisper     # + ffmpeg（macOS: brew install ffmpeg / Ubuntu: apt install ffmpeg）
  ```

  未インストールのときは AI ダイアログにその旨が表示され、他の機能はそのまま使えます。`CLIPSTUDIO_WHISPER_MODEL`（既定 `small`）でモデルサイズを変えられます。
- 文字起こしの対象はサーバーに保存済みの素材です（☁ の付いた素材）。
- AI 機能が使えない環境（キー未設定・バックエンドなし）でも、エディタの他の機能はすべて動作します。

## 開発

フロントエンドはビルド不要です。静的サーバーで配信するだけで動作します。

```sh
python3 -m http.server 8000
```

## デプロイ

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
GitHub Pages では静的なフロントエンドのみが配信されます（バックエンドは含まれないため、素材の保存は使えません）。
バックエンドと AI 機能も使う場合は、`uvicorn` を動かせるホストに配置し、エディタの ☁ ダイアログでその URL を指定してください。

# TaskMax

タグ・優先度・サブタスク・繰り返し予定に対応した、高機能なタスク管理アプリです。ビルド不要の素の HTML / CSS / JavaScript (ES Modules) で作られており、GitHub Pages でそのまま配信できます。

## 主な機能

- **4つのビュー**: リスト / カンバンボード（未着手・進行中・完了）/ 月間カレンダー / ダッシュボード
- **タスク詳細**: メモ、優先度、期限日時、タグ（複数）、サブタスク（チェックリスト）、繰り返し設定（毎日・毎週・毎月）、ピン留め
- **検索・フィルタ・並び替え**: 状態・期限・優先度・タグでの絞り込み、キーワード検索、手動ドラッグ並び替え／期限順／優先度順など
- **複数選択・一括操作**: 複数タスクをまとめて完了・削除・優先度変更
- **元に戻す (Undo)**: 削除などの操作をトースト通知から取り消し可能
- **ダークモード**: ライト / ダーク / システム設定に追従
- **ダッシュボード**: 完了率、優先度・タグ別の内訳、直近7日間の完了数の推移
- **インポート / エクスポート**: JSON バックアップの入出力、CSV エクスポート
- **期限通知**: ブラウザ通知 API による期限当日・期限切れの通知
- **キーボードショートカット**: `n` 新規タスク、`/` 検索、`1`-`4` ビュー切替、`Ctrl/Cmd+Z` 元に戻す、`?` ヘルプ
- **オフライン対応**: Service Worker によるアセットキャッシュ、ホーム画面への追加 (PWA)
- すべてのデータはブラウザの `localStorage` に保存されます（サーバー不要）

## 開発

ビルド不要です。`index.html` を静的サーバーで配信するだけで動作します。

```sh
python3 -m http.server 8000
```

## デプロイ

`main` ブランチへの push で GitHub Pages に自動デプロイされます（`.github/workflows/deploy.yml`）。
